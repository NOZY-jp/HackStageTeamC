# 探索資料・謎解き設計

『きみの好きな、わたし。』の作者・実装者向け資料。真相と解答を含む。以下は制作する資料の仕様であり、ゲーム実装や完成音声が既にあるという意味ではない。

## P0：散歩道から連絡箱へ〔通常〕

### 配置

喫茶店の写真の窓には、左から「鳥」「傘」「月」の絵葉書と、裏返った栞がある。展示に同じ絵がある。

展示説明：

> 窓に並ぶものを、左から。曲がり角の看板は、これから行く道を指す。

街路図：

| 現在地 | 選ぶ絵 | 次の場所 |
| --- | --- | --- |
| 入口 | 鳥 | 広場 |
| 広場 | 傘 | 橋 |
| 橋 | 月 | 連絡箱「まどぐち」 |
| 各場所 | その他 | 入口に戻る小道 |

写真の順番を街路図で使う。表栞をこの過程で必ず入手する。写真の裏返った四枚目は、ミラーで裏栞を探す任意のきっかけ。

### 獲得物

閉鎖挨拶と管理者への連絡箱。追加探索なしで再会へ進める。送信に回数制限を設けず、返事を受け取っても「出発する」を選ぶまでは探索へ戻れる。

## P1：二枚の栞〔隠し入口〕

### プレイヤーへ渡す実データ

表栞。三角は左上。

```text
▲
 B R N T
 O L A E
 U F G S
 C D H I
```

裏栞。○だけが透明な穴、■は不透明。三角は右下。

```text
 ○ ■ ■ ■
 ■ ○ ■ ■
 ■ ○ ■ ■
 ■ ○ ■ ■
        ▼
```

配布物説明は「二枚で一部屋。角の印を合わせて、上から読んでください」。展示には作家名検索がある。

### 操作と解答

裏栞を180度回し、三角の位置を左上へ合わせて重ねる。透明箇所は表栞の `(1,3), (2,3), (3,3), (4,4)` に重なり、上から **N A G I**。

回転なしだとB、L、F、Dだが、印が一致しない。印が正しい角度の根拠になる。

NAGIを作家検索すると、昔から公開されていた凪の作業室へ着く。現在のサムネイル一覧からは外れているが、配布物を使えば今も到達できる。認証突破は必要ない。

### なぜ残っているか

「ふたりの部屋」は、誰かの好きなものをたどって別の作家の部屋へ行く展示だった。栞は当時の配布物。失踪した凪が恋人のために暗号を作ったわけではない。

## P2：音の高さより、動き方〔原音へ到達する検索鍵〕

### プレイヤーへ渡す実データ

凪の「旋律の棚」は、題名をつける前の曲を音の形で整理している。冒頭八音を入力すると、該当する制作プロジェクトへ進める。カードを三枚総当たりするだけで原音に届く構造にはしない。

音を八つの点で示す。以下の数値は高さの単位。画面には数値目盛りと縦方向へ動かせる点の図、再生機能を置く。

```text
寝る用： 0, 2, 5, 4, 7, 5, 2, 0
棚の基準：最低音を3段目にそろえる
```

作業室の制作メモ：

> 声に合わせて高さを変えても、音から次の音への段差は変わらない。棚では、一番低い音を3にして検索する。

### 操作と解答

保存曲を3段上げて入力する。検索鍵は `3-5-8-7-10-8-5-3`。一致するのはtake17。文字列として打つ以外に、保存曲の図を移動して入力欄へ写す操作でもよい。

作者用の比較データ：

```text
take12： 8, 6, 3, 4, 1, 3, 6, 8
take17： 3, 5, 8, 7,10, 8, 5, 3
take21： 3, 5, 7, 8,10, 8, 5, 3
```

take12は上下反転、take21は3・4音目が異なり、上下への移動では保存曲に一致しない。検索失敗で資料を失ったり時間が進んだりはしない。

対応する制作プロジェクトへ入り、元録音を入手。名乗り、日付、公開曲と同じミス、同じ笑い声を照合できる。旋律が似ているだけで本人と断定しない。

音楽に詳しくなくても、点をずらして重ねれば解ける。聴覚だけに依存しない。

### 発見

ハルが「澪の作品」として好きになったものを、実際には凪が作っていた。さらに「寝る用」の書き出しと交際中のチャットを照合し、今の恋人までつながる。

## P3：二つのクレジット〔推論〕

### 組み合わせる資料

1. 追悼・保存案内：澪は2024年8月31日に死去。妹の作品を姉が保存。
2. 2026年5月22日のtake17：凪の名乗り。最初に好きになった公開曲と、演奏のミス・笑い声・椅子の音が同じ間隔で並ぶ元録音。
3. 7月9日の短い書き出し：「寝る用、途中で切る」という制作メモ。同じ夜のチャットに、眠れないハルへの「今日はドラムなし」と曲の添付がある。
4. 11月21日の保存者向けクレジット訂正予定：変更前のNAGIが、死後に作った新作も含めてMIOへ変わる。旧作者表示を読める作業室も閉鎖予定。
5. 配信主催者の公開連絡：「22日昼までに最終返答を。枠はそのまま」。演奏の辞退が確定する前であることが、最終会話前に分かる。

### 推論

「澪が生きている」「会うときだけ姉に入れ替わる」「送られたのは妹の遺した録音」では、現在の制作記録と、ハル個人向けの書き出しを説明できない。

「凪が会話も作曲もしていて、妹の名前を使っている」なら、資料が一つにつながる。Normalで同じ声が聞こえることは、澪が生きていた根拠にはならない。

## 会話への持ち込み

探索メモで、プレイヤーが次の組み合わせを作る。資料を集めただけで主人公が自動的に推理を喋り始めることはない。

| 会話に持ち込むこと | 結びつける根拠 | プレイヤーが選ぶ解釈 |
| --- | --- | --- |
| 好きになった曲を作った本人 | 公開曲＋take17の元録音＋7月9日のチャットと書き出し | 妹の遺した曲ではなく、凪が作り、凪が送っていた |
| 今、なくそうとしているもの | 変更前後の作者表＋澪の追悼案内 | 妹の場所の保存ではなく、生きている姉の作者名が失われる |
| まだ本人に聞けること | 演奏会告知＋主催者の返答期限＋彼女の「見てほしい」 | 夕方の出演は元から本人が望んだもので、最終返事はまだ |

メモの結論は「話したいこと」として保存する。「本当の恋人は澪」「会うときだけ姉へ交代」「MIOの作品が消される」などの誤った仮説も選べるが、対応しない根拠を選んだ場合には、会話前に同じ資料を見直せる。何度でも組み直せる。

最終会話では、プレイヤーがこのメモを添付し、本人と好きになった作品の対応を示す。続いて作者名の変更予定と、本人が見てほしかった曲の話を出す。資料の枚数や好感度で分岐しない。

必要な三つの結びつきが揃えば新しい会話を最後まで進められる。正しい名前だけを入力しても、どうして自分に関係する話なのかを彼女へ届けられない。これは名前当てではなく、根拠を伴った働きかけの分岐。

真実は会話前に知れる。会話は答えを教える場ではなく、分かったことを相手へ伝えて展開を変える場。

## 再探索

Normalの後に証拠は増えない。同じ探索をやり直せば隠し入口へ到達できる。章選択で会話前に戻れるが、初回でもTrueへ行ける。

## 素材制作時に守ること

- take17の原音を、公開曲の実際の素材に使う。似た別演奏を同じ録音と呼ばない。
- 保存曲は同じ旋律を実際に移調して演奏する。
- 栞の文字、穴、角の印は、装飾の都合で変えない。
- Normalのスマートフォンに真相の読める画面を出さない。
- 表栞は必ず通常探索で手に入る。裏栞は写真と配布物説明から探せる。
- 出会いは5月22日、交際開始は6月17日、個別の曲を送ったのは7月9日。日付を混同しない。
- 凪の出演・名義変更は本人が最終決定する。主人公が他人のアカウントへ入って操作しない。
- 出演と恋愛の継続は別々に意思確認する。出演しなければ愛されない、という条件にしない。
