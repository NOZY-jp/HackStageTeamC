# サーバー構成と DM 一覧

## 1. サーバー（3つ）

### A. `mhc` モンハンコミュニティ（既存・拡充）

- 「**昔からある**コミュニティ」。2025-02 以前の会話も少量作ってよい（`2024-06` まで遡る案。**D8**: 遡るなら最大1年、件数は200通まで）
- テキスト 5 → **8ch**: `マルチ募集` / `雑談` / `質問` / `クリップ` / `装備相談`（新）/ `募集・告知`（新・読み取り専用） / `自己紹介`（新・ピン留め） / `落ち葉`（新・雑談の続き置き場）
- ボイス 3 → **4ch**: `集会所1` / `集会所2` / `狩り準備`（既存） / `作業通話`（新）
- 特徴: 未返信の募集が普通にある。常連と一見が混ざる。荒らしは1回だけ通報される

### B. `univ` 大学の学科（新・仮名「◯◯大学 情報学科24」）

- メンバー 120（背景含む）。**同級生・先輩・後輩の主要な場**
- テキスト 6ch: `連絡` / `履修・課題` / `雑談` / `バイト・就活` / `レポート共有`（ファイル名だけ） / `なんでも`
- ボイス 2ch: `作業通話` / `雑談VC`
- 特徴: 課題締切前夜に集中。誤字・愚痴・「だれか〇〇のレポート持ってる」が多い。先生の話題は名字のみ

### C. `friend` リア友（新・仮名「いつメン」）

- メンバー 20（実質 6〜8人が喋る）。**写真・スタンプ・誘い・返信が遅い**
- テキスト 3ch: `雑談` / `予定` / `思い出`（画像だけの投稿が多い）
- ボイス 1ch: `通話`
- 特徴: 1日に10通の日と、1週間無人。呼び方はあだ名固定

### 共通の型

- `Guild` 型は既存のまま（`categories` / `channels` / `iconColor` / `initials`）。**型の追加はしない**
- `urlId` は17〜19桁の数値風文字列で**グローバル一意**（`guilds.ts` の連番を踏襲: `1187002356428840961` 系の次の空き帯）
- 並びは定義順（`Guild` に `position` は無い）。サーバーレールは 3つ表示

## 3. 呼称・禁止事項（DM 共通）

- **本名を書かない**。MaiMai と琥珀は互いの本名を知らない
- カイを文中で「χ」と書かない（表示名のみ）。会話では「カイさん」
- 住所・丁目・番地・号室を書かない（既存テスト）
- 旧ハンドル `hunter_denden3243` を新規データに出さない
- 新サーバー・新DM は**謎解きの手がかりを増やさない**（順序の導線は既存のまま）

## 4. 通話履歴の持ち方（D6）

新しい型を**足さない**方針を第一案にする（既存の `Message.system` を拡張）:

- DM: 既存どおり `通話を開始しました` / `通話を終了しました` の**システムメッセージ2通**（`system: true`、`authorId` は発信者）
- 不在着信: `通話を開始しました` の直後に `応答がありませんでした`（`system: true`）。終了メッセージは付けない → **テストは「不在着信は開始＋応答なしの対」として扱う**
- 通話時間を出すため、`VoiceSession` 型（`id`, `scope: "dm"|"guild"`, `channelId`, `participantIds`, `startedAt`, `endedAt`, `endedReason: "hangup"|"missed"`）を `lib/discord-like/types.ts` に追加し、`data/voice-sessions.ts` に置く（UI は「◯分」をここから読む）
- サーバー VC: `〜がボイスチャンネルに参加しました` / `退出しました` のシステムメッセージ＋`VoiceSession`
- **開始/終了は必ず対**（既存テストの「開始と終了が同数」を維持）。不在着信は `endedReason: "missed"` で区別し、既存テストの同数条件から除外する形に更新
