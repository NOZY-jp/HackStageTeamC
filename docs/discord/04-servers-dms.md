## 1. サーバー（3つ）

### A. `mhc` モンハンコミュニティ

- 「**昔からある**コミュニティ」。2025-02 以前の会話も少量作ってよい（`2024-06` まで遡る案。**D8**: 遡るなら最大1年、件数は200通まで）
- テキスト **7ch**: `マルチ募集` / `雑談` / `質問` / `クリップ` / `お知らせ`（＝告知） / `装備相談` / `自己紹介`。**8ch目は設けない**
- ボイス **4ch**: `集会所1` / `集会所2` / `狩り準備` / `作業通話`
- 特徴: 未返信の募集が普通にある。常連と一見が混ざる。荒らしは1回だけ通報される

### B. `univ` 大学の学科「◯◯大学 情報学科24」

- メンバー 120（背景含む）。**同級生・先輩・後輩の主要な場**
- テキスト 6ch: `連絡` / `履修・課題` / `雑談` / `バイト・就活` / `レポート共有`（ファイル名だけ） / `なんでも`
- ボイス 2ch: `作業通話` / `雑談VC`
- 特徴: 課題締切前夜に集中。誤字・愚痴・「だれか〇〇のレポート持ってる」が多い。先生の話題は名字のみ

### C. `friend` リア友「いつメン」

- メンバー 20（実質 6〜8人が喋る）。**写真・スタンプ・誘い・返信が遅い**
- テキスト 3ch: `雑談` / `予定` / `思い出`（画像だけの投稿が多い）
- ボイス 1ch: `通話`
- 特徴: 1日に10通の日と、1週間無人。呼び方はあだ名固定

### 共通の型

- `Guild` 型は既存のまま（`categories` / `channels` / `iconColor` / `initials`）。**型の追加はしない**（#163 でサーバーごとの `memberIds` を後から追加）
- `urlId` は17〜19桁の数値風文字列で**グローバル一意**（`guilds.ts` の連番を踏襲: `1187002356428840961` 系の次の空き帯）
- 並びは定義順（`Guild` に `position` は無い）。サーバーレールは 3つ表示

## 4. 通話履歴の持ち方（D6）

台本の通話行に `system: true` を付け、実際の発着信を履歴に表示する。

- DM: 既存どおり `通話を開始しました` / `通話を終了しました` の**システムメッセージ2通**（`system: true`、`authorId` は発信者）
- 不在着信: `通話を開始しました` の直後に `応答がありませんでした`（`system: true`）。終了メッセージは付けない → **テストは「不在着信は開始＋応答なしの対」として扱う**
- 通話時間を出すため、`VoiceSession` 型（`id`, `scope: "dm"|"guild"`, `channelId`, `participantIds`, `startedAt`, `endedAt`, `endedReason: "hangup"|"missed"`）を `lib/discord-like/types.ts` で定義し、`data/voice-sessions.ts` で組み立てる（UI は「◯分」をここから読む）
- サーバー VC: `〜がボイスチャンネルに参加しました` / `退出しました` のシステムメッセージ＋`VoiceSession`
- 発信は接続後の終了か応答なしと対になる。不在着信は `endedReason: "missed"` で区別する
