# 自然さの基準（AI臭の除去）

## 1. 台詞の書き方

- 話し手がその場にいる理由と、相手が何を知っているかを決めてから、一連のやり取りを一通ずつ書く。
- 前の発言を受けて答えたり、聞き返したり、別の話を始めた理由が読み取れるようにする。月をまたぐ話題は、前回までに話したことを踏まえて進める。
- 言い直し、連投、返事のない誘い、スタンプだけの反応は、その人物と場面に合うときに使う。

## 2. 送信時刻

話している最中の短いやり取り、仕事や授業で返事が遅れる日、会話のない日を場面に応じて書く。日時が変わると意味が変わる台詞は前後を読む。交際後の頻度は D1 の決定を参照する。

## 3. 確認の仕方

作中と同じ順でログを通して読み、質問への返事、温度差、直前の出来事、後日回収する話題を確認する。誤字・スタンプ・画像/リンクのみ・深夜の短文は**存在すること**だけを確認し、件数のノルマは置かない。

## 5. 通話（VC）の履歴

- **DM 通話**: `通話を開始しました` / `通話を終了しました` のシステムメッセージ（既存形式）に、**通話レコード**（開始・終了・通話時間・発信者・不在着信）を併設する
- **サーバー VC**: 入室/退室のシステムメッセージ（`〜がボイスチャンネルに参加しました` / `退出しました`）と、**VC セッション記録**（誰が・いつ・何分）
- 不在着信（`応答がありませんでした`）を混ぜる。**通話は必ず対で閉じる**（テストで固定）
- 通話中はテキストが減る／通話後に「さっきはありがとう」が来る、という連動を作る

## 6. 自動検査

発言者と所属、日時、通話の対応、関係の設定、謎解きの公開順、検索や履歴での表示を確認する。会話量は月別・会話先別に確認し、空白や偏りの理由を実際のログで読む。

- 呼称: **廃止した旧呼び名はデータ0件**、本名は結末以外に出さない（テストで固定）
- 自然さの6指標（未回答15%以下・評価語単独1ch1回・バースト・時刻整合・呼称表・表記ゆれ）は `naturalness.test.ts`
