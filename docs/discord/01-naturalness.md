# 自然さの基準（AI臭の除去）

## 1. 台詞の書き方

- 話し手がその場にいる理由と、相手が何を知っているかを決めてから、一連のやり取りを一通ずつ書く。
- 前の発言を受けて答えたり、聞き返したり、別の話を始めた理由が読み取れるようにする。月をまたぐ話題は、前回までに話したことを踏まえて進める。
- 言い直し、連投、返事のない誘い、スタンプだけの反応は、その人物と場面に合うときに使う。

## 2. 送信時刻

話している最中の短いやり取り、仕事や授業で返事が遅れる日、会話のない日を場面に応じて書く。日時が変わると意味が変わる台詞は前後を読む。交際後の頻度は D1 の決定を参照する。

## 3. 確認の仕方

作中と同じ順でログを通して読み、質問への返事、温度差、直前の出来事、後日回収する話題を確認する。誤字・スタンプ・画像/リンクのみ・深夜の短文は**存在すること**だけを確認し、件数のノルマは置かない。

## 5. 通話（VC）の履歴

- **DM 通話**: `通話を開始しました` / `通話を終了しました` のシステムメッセージ（既存形式）に、**通話レコード**（開始・終了・通話時間・発信者・不在着信）を併設する
- **サーバー VC**: 入室/退室のシステムメッセージ（`〜がボイスチャンネルに参加しました` / `退出しました`）と、**VC セッション記録**（誰が・いつ・何分）
- 不在着信（`応答がありませんでした`）を混ぜる。**通話は必ず対で閉じる**（テストで固定）
- 通話中はテキストが減る／通話後に「さっきはありがとう」が来る、という連動を作る

## 6. 自動検査

発言者と所属、日時、通話の対応、関係の設定、謎解きの公開順、検索や履歴での表示を確認する。会話量は月別・会話先別に確認し、空白や偏りの理由を実際のログで読む。

- 呼称: **廃止した旧呼び名はデータ0件**。**「リョウ」はリア友・大学のチャネルと結末だけ**、それ以外は0件（テストで固定）
- 自然さの6指標（未回答15%以下・評価語単独1ch1回・バースト・時刻整合・呼称表・表記ゆれ）は `naturalness.test.ts`

## 沈黙と再開（#202）

- DM は毎日連投にしない。3日以上の沈黙が、恋人15回以上・用件8回以上・学科10回以上・リア友8回以上ある。
- 7日以上空いたあとの第一声は、挨拶・謝罪・報告・写真・生存確認のいずれかで始める（「〜の件だけど」のような用件だけの再開にしない）。
- 21日以上の沈黙は許容する（データの期間と出来事の都合）。

## 精度と温度差（#252 第6ラウンド）

`lib/discord-like/temperature.test.ts` で、以下の5つの精度指標を検証する（`test-thresholds.ts` の `TEMPERATURE_LIMITS` で下限を固定）。

1. **返信の温度差**: 応答・感謝の語形および文体を `softEmoji`（柔らかめ・絵文字・`〜`/`ね`＝恋人 `dm-maimai` の MaiMai）、`keigo`（`ありがとうございます`/`助かります`/`了解です`/`です・ます`＝敬語関係 `dm-ootsuka`・`dm-hayashi`・`dm-kai`・学科先輩後輩組）、`tameguchi`（`ありがと`/`助かる`/`了解`/`りょ`/`おけ`/常体＝リア友・`mhc` 常連）に分類し、3×3のクロス集計（$\chi^2$ 検定）で統計的分離を確認する。水増しを避け自然な絵文字頻度を保つため `dm-maimai` の `softEmoji` が9件となり `minExpectedCount` 下限は2（実測2.30）としているが、応答語形 $\chi^2=63.31$・発話全体文体 $\chi^2=579.21$ で統計的分離を確認している。
2. **話題の引き継ぎ**: バースト内の話者交代ごとに、直前の相手発話の具象名詞・ドメイン語・活用動詞語幹を次の返信が受ける率を、DM グループ別（実測 4.6%〜7.8%）およびサーバーのテキスト16ch別（実測 1.4%〜17.0%）に下限で固定する（各実測値と下限は `test-thresholds.ts` に併記）。英字・カタカナ・数字+単位・漢字のいずれもトークン境界付きで照合し、動詞語幹も活用語尾と前後境界を確認するため、「CD」と「LCD」、「猫」と「猫背」、「傘を持っていく」と「持ち株」などの部分一致・複合語一致は数えない。
3. **未読の現実味**: 未読 DM スレッド数は 2〜4本（実測3本: `dm-ootsuka`・`dm-hayashi`・`dm-gunlance`）、うち1本以上が `GAME_NOW` から24時間以上前の放置未読とする。`unreadCount` は `dm-threads.ts` で自動導出する。
4. **通話の文脈**: `dm-maimai` の全22通話（接続16・不在6）で、通話開始直前2通（非システム）以内の誘い・終了直後2通以内の感想、および不在着信6件すべてに対するかけ直しの実行または申し出を確認する（謝罪・言い訳だけでは通さない）。
5. **会話の長さの分布**: 30分バースト内の通常発言通数の中央値と P90 をスレッド種別（恋人・カイ・その他DM・サーバー）ごとに `[min, max]` 範囲で固定し、極端な短文のみ／長文のみへの偏りを防ぐ。
