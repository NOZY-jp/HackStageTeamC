# 自然さの基準（AI臭の除去）

会話データを作るときの規則。**規則は文章ではなくテストで固定する**（`lib/discord-like/naturalness.test.ts`）。

## 1. 禁止（AI臭の正体）

- 全員が丁寧で、毎回オチがつき、必ず返信が揃う会話
- 1つの話題に対して全員が順番に1回ずつ反応する（点名簿のような並び）
- 毎回きれいに結論を出す／「まとめると」「〜ってことだね」で締める
- 同じ語彙・同じ長さ・同じ句読点。全員が「w」も「笑」も使わない
- 完璧な誤字なし。1メッセージ1論点だけ
- 感情の起伏がなく、誰も愚痴らない・話題を変えない

## 2. 必ず混ぜる（比率は目安、テストで下限だけ固定）

| 要素                                               | 目安                 | テストで固定する下限 |
| -------------------------------------------------- | -------------------- | -------------------- |
| 未返信で終わる会話（最後の発言に誰も返さない）     | 全スレッドの 20〜30% | 10%以上              |
| 既読スルー（質問や誘いが流れて別の話題へ）         | 全スレッドの 25%     | 8件以上              |
| 連投（同一人物が2〜3通連続）                       | 全体の 10%           | 30回以上             |
| 誤字・言い直し（`*` 訂正、変換ミス、送信先間違い） | 全体の 2%            | 8件以上              |
| スタンプ/絵文字のみの1通                           | 全体の 3%            | 10件以上             |
| 画像・リンクのみの1通                              | 全体の 2%            | 6件以上              |
| 話題の中断（会話が途中で別の話題に置き換わる）     | 全スレッドの 15%     | 5件以上              |

## 3. 返信間隔（人が実際に打つ速さ）

| 間隔     | 目安 | 使いどころ                             |
| -------- | ---- | -------------------------------------- |
| 1〜3分   | 25%  | 同時に起きている時間帯（通話前後・夜） |
| 5〜40分  | 40%  | 家事・ゲーム中・移動中                 |
| 1〜6時間 | 20%  | 仕事・授業・風呂                       |
| 翌日以降 | 15%  | 寝落ち・興味が薄い・怒っている         |

- **深夜（0:00〜3:00）** は短文・誤字が多い。**早朝（5:00〜8:00）** は「おはよう」だけの1〜2通
- **休日の昼** は長文・連投が多い。**平日の日中** は1〜2通で終わる
- 会話しない日を作る（D1: 週5日以上、連続3日までは空白可）

## 5. 通話（VC）の履歴

- **DM 通話**: `通話を開始しました` / `通話を終了しました` のシステムメッセージ（既存形式）に、**通話レコード**（開始・終了・通話時間・発信者・不在着信）を併設する
- **サーバー VC**: 入室/退室のシステムメッセージ（`〜がボイスチャンネルに参加しました` / `退出しました`）と、**VC セッション記録**（誰が・いつ・何分）
- 不在着信（`応答がありませんでした`）を混ぜる。**通話は必ず対で閉じる**（テストで固定）
- 通話中はテキストが減る／通話後に「さっきはありがとう」が来る、という連動を作る

## 6. 検証（テスト）

`lib/discord-like/naturalness.test.ts` で以下を固定する:

1. 未返信率・既読スルー件数・連投回数・誤字件数・スタンプのみ件数が下限以上
2. 返信間隔の中央値と、`1分未満` の割合が 40% を超えない（＝機械的な即レスばかりにしない）
3. 1日の発言数の分散（同じ件数の日が続かない）
4. 通話の開始/終了が対で、通話時間が実時間の範囲（1分〜6時間）
5. 関係性ごとの頻度上限（例: χ との DM は月6回以下）
6. 呼び方の固定（`MaiMai` を「ゆい」と呼ばない、カイを「χ」と文中で書かない等）
