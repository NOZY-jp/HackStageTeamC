- **精密設計区間**: `2025-11-20` 〜 `2026-11-20`（ちょうど1年）。日付・曜日・時刻を全部整合させる
- **既存区間**: `2025-02-03` 〜 `2025-11-19`。既存の 436通（DM）＋770通（mhc）は**残す**（削らない）。必要なら薄い追記のみ

## 4. 曜日・時刻の扱い

- 平日の日中（9:00〜17:00）は学科サーバーのみ賑わう。DM は 12:00〜13:00 と 19:00 以降
- 週末の昼（11:00〜16:00）は `dm-maimai` とリア友サーバーが長い
- 深夜 0:00〜3:00 は短文・誤字・寝落ち（通話が「終了」で切れる）
- **同じ時刻に2人を同時に喋らせない**（送信時刻は全チャンネル横断で一意。既存テストの昇順・重複なしを維持）
- 祝日（2025-12-31〜2026-01-03、2026-05-03〜05-05、2026-08-13〜08-16）は反応を変える

## 5. 既存テストとの差分

| 既存の検証                         | 新しい扱い                                                          |
| ---------------------------------- | ------------------------------------------------------------------- |
| DM 350〜450通・サーバー 700〜900通 | DM **1,400〜1,650**・サーバー **2,500〜2,900**（サーバーは3つ合算） |
| 期間比（1/9・4/6・7/3 …）          | 月次の `dm : server` 比（下表）に置き換え                           |
| 「付き合った後は毎日やり取り」     | **週5日以上・連続空白3日まで**（D1）                                |
| サーバーは1つだけ                  | **3つ**（`mhc`・`univ`・`friend`）。旧3サーバー名は引き続き禁止     |
| DM は2件                           | **9件**                                                             |

月次の `dm : server` 比（±25%）: 2025-11〜2026-02 = 1:1.2 / 2026-03〜06 = 1:1.5 / 2026-07〜08 = 1:1.8 / 2026-09〜11 = 1:1.3

**改訂（2026-11-21・PM決定）**: DM 1,500通・サーバー2,690通のため、**固定の比（±25%）ではなく「後半ほど DM が濃くなる傾向」を検査する**（`trendMultiplier`＝後半/前半の比が一定以上）。理由: 絶対値の比は総量の変更で成立しなくなり、設計意図（付き合った後に個人DMが濃くなる）は傾向で表現できる。旧比 1:1.2/1:1.5/1:1.8/1:1.3 は**参考値**として残す。実測（2026-11-21時点）: 0.156 / 1.287 / 1.263 / 1.503。
（DM が濃くなる秋に比を下げる＝恋人との個人DMが増える）
