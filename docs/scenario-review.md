# シナリオ推敲記録

## 保存方針

各稿はjjコミットで保存する。評価が下がった部分も前の版から復元できるよう、履歴を潰さない。人間の試読結果と、AIによる自己批評は区別する。

## 第1稿

### 書いたもの

死んだ妹の名前で恋をしていた姉。Normalでは恋を守るため自分の名前と音楽を捨てる。Trueでは、主人公が既に本人の曲と人柄を好きだった証拠を届け、自分の名前で恋も音楽も続ける。

### 残す価値があるもの

- Normalの誕生日ケーキが、真相を知ると死者の誕生日を祝い続ける場面に変わる。
- Trueで同じ声に本人の名前がつき、最初に好きになった笑い声が実際の演奏に戻ってくる。
- 「好かれるために自分を消す」から「既に好きになってもらっていた自分を認める」への変化がテーマと結びつく。

### 第1回の批評

1. 最大の弱点は隠し探索。「画像を重ねる」「クレジット復元」と書いただけで、実際の問題と解法が存在していない。現状では条件を満たしていない。
2. 誰が何を作ったかはクレジットを読めば分かってしまう。探索を作業にしないため、欠落した資料をどう復元し、矛盾をどう解消するかまで必要。
3. 自分の存在を消すと断言しているが、ケーキ一つで永久の自己喪失を証明できない。本人が選ぶ具体的な行動と、探索で確認できる準備を対応させる必要がある。
4. 恋人に会いたくないほど迷っていた人が、フォーム一通で一生妹として生きると決める。変化が急で、因果が弱い。
5. 出演会が最終日に偶然あると、主人公が救うための仕掛けに見える。会う日と演奏予定のつながりを初期の会話から作る必要がある。
6. 主人公が「凪さん」と呼ぶだけで解決すると、名前当ての正解報酬になる。嘘への傷と、相手自身を好きになった根拠を会話で扱う必要がある。
7. 失踪理由を自信不足から変えたいという相談に対し、結局ただの自信不足へ戻っていないか。妹の作品を守る役割と、好かれるための振る舞いが絡み、既に成立していた二重生活が初対面で破綻する因果へ深める必要がある。
8. 親戚設定は必須条件ではなく候補。無理に残して話を重ねるより、今回は妹と姉の本人性を一つの中心に据える。ただし、ユーザー確定設定とは扱わない。

### 次稿の方針

実際に解ける資料と問題を作る。自己喪失を劇的に宣言する台詞を増やすのでなく、本人名義の公開・演奏を取りやめる準備を探索で発見させる。死亡の事実を煽りに使わず、姉妹それぞれの具体的な好きと、妹が姉の作品を好きだった事実を描く。

## 第2稿

### 改稿

チャットから再会、二つの結末まで台詞にした。栞の重ね合わせと、移調した曲の照合に具体的な入力・操作・解答を付けた。演奏会の予定を会う約束以前へ置き、妹が姉の音楽を待っていた会話も追加した。

### 第2回の批評

1. 6月17日から11月22日までは正確には半年ではない。出会いと最初の感想・交際開始の日時を分けるか、期間の表現を直す。
2. 通常の探索は簡単でよいが、隠し入口へのきっかけは同じ写真にある裏返った栞から自然に伸ばす必要がある。
3. 単なる活動休止を自己喪失と断定しない。自分の作者名を既存作品からも外し、亡くなった妹に帰属させる具体的な選択が核心。
4. 資料を持っているだけで解答選択肢が自動生成されると、推理が自動化される。何と何を対応させたかをプレイヤーが示す方式にする。
5. 内部の移管操作一覧が公開されるのは不自然。作品の再公開・権利表示の訂正告知へ変える。
6. 元録音だけで現在の恋人を断定しない。当日のチャットと保存曲の書き出しで、声・作品・日々の会話を結ぶ。
7. 「眠れなかった夜に起きていたのは誰？」は相手を正答へ誘導する質問に聞こえる。具体的なお礼と、主人公自身の不格好な本音に置き換える。
8. 真相を知っていてNormalを選ぶ場合、主人公が急に無知な台詞へ戻らないようにする。「今日は触れない」と本人が選ぶ意味になるよう区別する。
9. 演奏会へ出ることを交際の条件にしない。出演とは別に、二人とも関係を続けたいと明確に伝える。
10. 誕生日にまた料理を失敗しただけでは、本人の好きが戻ったことが見えない。本当の好みを本人が選んでいる場面を足す。

### 突飛な代案

- 二人の姉妹が交代で一人の恋人を演じる：二人分の恋愛と交代時期が必要になり、中心がぼける。二枚の栞と共同制作だけ残す。
- 再会時に肉体が姉へ交換される：超常・技術設定が新たに必要。今回は不採用。
- 主人公が過去の事故の原因だった：罪の清算が中心になり、届けたい一歩が変わるため不採用。
- 妹は実は生きていた：資料を信じて謎を解く行為を後から無効にするため不採用。
- 妹が姉の自分名義の曲を最初に待っていた：姉が妹を消さずに自分の名前を戻せる根拠になる。通常の古い制作会話として採用し、予言や都合のよい遺言にはしない。

## 第3稿

### 改稿

- 最初に真相を一括開示する構成をやめ、プレイヤーの発見順に読み進められる本文へ変更。裏の時系列は末尾へ移した。
- 出会い5月22日、交際開始6月17日、個別の曲7月9日を区別した。
- 音の比較を三枚の候補をクリックするものから、保存曲を基準の高さへ移し、旋律検索の鍵を作る操作へ変更。
- 権利表示の変更は内部の流出画面ではなく、保存者向けに公開された訂正告知とした。
- ハルの誘導的な質問をやめ、具体的な夜の感謝と、嘘を知らされた痛み、それでも会い続けたい本音を言わせた。
- 演奏会より先に、双方が恋人としてこれからも会いたいことを確認。彼女が自分で出演と作品の扱いを決める。
- 誕生日の好物もまだ取り違える後日談を加え、正体を知れば全て分かるという終わりにしない。

### 第3回の批評

1. Trueでケーキの文字を主人公が勝手に書き換えると、本人に名乗らせる場を奪う。現稿は指で隠して本人へ呼ばれたい名を聞くため、この問題を回避できている。
2. Normalで自分名義の活動が終わるのは、彼女が自分でしていること。恋愛自体が悪い、音楽を続ける人の方が偉い、という評価にならないようにする。本人が出たかったこと、MIO名義に変える理由が愛を失う恐怖であることが必要。現稿は資料と会話の双方で示す。
3. Trueの相手が泣けば主人公が無条件で許す構図にはしない。名前が違ったことの痛みを言い、誤った名前を続けない約束を置く。現稿は双方の意思を描くが、謝罪後すぐ結末へ急がず、沈黙と実際の新しい連絡先を間に置く。
4. 読み手にテーマを解説する文が演奏の余韻へ混じっている。作品内で表示する台詞・画面と、作者向けの説明を最終稿で明示的に分ける。
5. Normalの翌年の約束だけで「絶対に一生戻れない」とは言えない。闇は永久の人格消滅という誇張ではなく、今、死者の名前を自分の幸福の条件にしてしまい、作者としての自分を公に消す実行にある、と限定する。
6. 日付と検索鍵の計算が本当に一致するか、完成稿の資料から検算が必要。物語の説得力を検算結果だけで保証したとは言わない。
7. 再会前に知るべき情報が、会話で初めて確定しないかを確認する。出演を見せる予定だった意図は既存のDMと告知、本人性は原音と現在の制作で到達できる。最後の会話は説明会ではなく、その本人へ何を言うかに使う。

### 感性についての自己評価

守るべき箇所は、最初の「そこも」、焦げたトースト、眠れない夜に短すぎる曲を送るやり取り、Normalの名前入り写真、Trueで本人に名前を尋ねる沈黙、録音を止めずに続ける演奏。これらは概念の説明でなく、同じ人を好きになる具体的な時間として機能する。

驚きは「恋人が死んでいた」だけではなく、「死んだと思った相手との、好きだった時間は生きている本人のものだった」「会うことは本人を救うとは限らない」という二段階。死者の復活や新しい黒幕で証拠を覆さない。

人間による試読はまだ行われていない。自己批評は、人間が感動したことの実測ではない。各版をjj履歴に残し、読み手が別の版の表現を好んだ場合に取り戻せる状態にする。

## 提出稿：第4稿

### 最終の推敲

- ケーキの文字を指で隠す象徴的な動作を削り、顔を見て、呼んでほしい名前を聞く場面へ戻した。意味を演出で押しつけるより、本人が名乗る時間を残す。
- 演奏後にテーマを説明する独白を削り、古い作品と新しい曲の作者名が並ぶ画面へ置き換えた。
- 名前を取り違えた当日の写真を、本人が消さずに残す。過去を完全に消せたから幸せになった、という結末を避けた。
- 後日談のケーキを「名前だけ合っている予約画面→好みを聞き直す→当日の写真」の順に直し、予約後なのにケーキが既に来ている時系列を修正した。
- 主催者の返答期限を13時に明示。12時の再会後に話しても出演の最終返答が間に合うようにした。
- 架空SNSの休止・履歴保存・再開を明示。アカウントを不可逆に消した後に復活する不整合を避けた。
- 作者向けの説明と、ゲーム内の台詞・画面指定を区別。Normalへ不穏なBGMや長すぎる間を加えないよう指定した。
- 探索の実データに、作者名の変更前後、個別の曲の制作メモ、主催者の連絡を追記した。実装時に核心の証拠が曖昧なままにならないようにした。

### 条件との照合

| 条件 | 提出稿での根拠 | 評価 |

| Normalは見かけ上幸せ | 同じ声の恋人と会い、誕生日を祝い、手をつなぎ、次に会う約束をする | 成立 |

| 真実を事前に知れる | 追悼資料、原音、現在のDMとの符合、作者名の訂正告知が全て探索中にある | 成立 |

| 意外性 | 死者の復活と思わせうる状況から、生きた姉の本人性へ。普通の再会が自己抹消の確定にもなる | 実際の驚きの大きさは試読で検証する余地がある |
