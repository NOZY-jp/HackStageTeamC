# きみの好きな、わたし。

## 初稿の物語

2026年11月22日、ハルはネットで半年付き合った「澪」と初めて会う。前日の夜、彼女のアカウントが消えた。

最後のDMは「ごめん。明日、行けない」。

彼女は、短い音楽と絵を組み合わせた作品を公開していた。ハルが好きになったのは、完成作に残っていた小さな笑い声だった。曲の最後に録音を止め忘れたらしい音が入り、彼女はそれを消さずに公開していた。

「なんでここ残したの」と尋ねたハルに、彼女は「君がいいって言ったから」と答えた。

会う約束の直前、ハルは彼女が作曲をやめたがっていることを知る。「会えたら、もう作らなくてもいい」と彼女は言う。ハルは、自分と過ごす時間を優先したいという意味だと思っていた。

## 普通の探索

作品ページの下書き、二人で作ったプレイリスト、待ち合わせ場所を写した写真を調べる。写真の撮影地点と、プレイリストに残った曲の順番を使い、連絡用の小さな作品ページへ着く。

そこには「澪はもうここにはいません」とある。しかし、閉鎖前に一度だけ届く連絡フォームが残っている。ハルは「それでも会いたい」と送る。

返事は「明日、約束した場所で」。

## Normal Ending

待ち合わせ場所に来た女性は、ハルが知る声で「お待たせ」と言う。

ハルが澪と呼ぶと、彼女は少し遅れて返事をする。

「本当に、私でいいの」

「君だから、ここまで来た」

彼女は泣いて笑う。二人は恋人として歩き出す。ハルが、もう作品を消さなくていいと言うと、彼女は「ううん。これからは、あなたといる」と答える。

後日、二人は彼女の誕生日を祝う。ケーキには「MIO」の文字。彼女は「来年も、これがいい」と言う。ハルは写真を撮る。幸福な日常の始まりとして閉じる。追加の不穏な通知や種明かしはない。

## 隠された真相

澪は二年前に亡くなっている。今の恋人は、姉の凪。もともと姉妹で共同制作していたアカウントを、妹の死後も凪が続けていた。

ハルと話し始めたとき、妹の名前で呼ばれ、訂正できなかった。妹の作品が好きだったハルが、自分を好きになるとは思えなかった。

ハルが好きになった曲と、消し忘れた笑い声を入れたのは凪。彼女は妹を演じていたつもりで、自分の好きなものを少しずつ混ぜていた。それをハルは知らずに好きになっていた。

会う前日、凪は自分名義の音楽活動を閉じる準備をする。澪として生きるなら、凪の作品や名前が残っていてはいけないと思った。逃げようとして恋人のアカウントを消すが、ハルから連絡が来ると、凪をやめて澪として会う決心をする。

Normalは、死んだ妹の人生を一生演じる覚悟をした人と、事情を知らないまま結ばれる終わりである。恋が成就した代わりに、自分名義の音楽も本当の誕生日も失う。

## 隠し探索

通常探索で見つかる絵の裏面と、別の作品の透過画像を重ねると、共同制作者の作業室へのリンクが現れる。

作業室では、音楽と絵の担当者をクレジットの欠片から復元できる。最後に曲の公開日時と、妹の追悼ページの日付を照合し、付き合っていた半年間の相手が凪であると推理する。

凪名義の未公開曲と、11月22日の小さな演奏会への出演予定を見つける。彼女は出演を取り消そうとしていた。

## True Ending

Normalと同じ再会の場面で、ハルは彼女の名前を呼ぶ前に、復元した曲を提示できる。

「これが好きなんだ。誰が作ったか、本人に聞きたかった」

彼女は「妹のものだから」と答えようとする。しかし、ハルは制作記録と、曲の中に残る彼女自身の演奏を示す。

「凪さん」

彼女は返事をする。初めて、自分の名前で。

ハルは嘘がつらかったことを伝える。凪も謝る。そのうえで、彼女の曲を好きになり、一緒に過ごした本人に会いに来たことを伝える。

凪は、自分の出演取り消しをやめる。ハルが客席に座る中、彼女は凪として自分の曲を演奏する。完璧には弾けず、間違えて笑う。ハルが最初に好きになった笑い声が、今度は目の前で聞こえる。

後日、二人は凪の本当の誕生日を祝う。妹の作品も消さず、姉妹それぞれの名前をクレジットに残す。

「次に会う日、いつがいい」

「私の誕生日」

「まだ先じゃない？」

「その前にも、会うけど」

二人は、今度は実際の彼女の好物を食べに出かける。
