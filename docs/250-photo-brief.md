# #250 残りの画像素材

各行につき1枚。人物のいる4枚は、既存の卒業式画像に合わせたアニメ調で、橙髪と黒髪ボブの二人を同じ顔立ちで描く。全画像とも実在人物に似せず、読める文字・校章・ロゴ・地名を入れない。

卒業式では左の橙髪がかのん、右が黒髪ボブ。Twixer の自画像（kanon-avatar.svg）は卒業式のかのんに合わせて橙髪に統一する。既存のカフェ・アルバム・入学式の仮画像では、橙髪の人物が右側にいる。

| 用途                                 | 画素サイズ | 構図                                                                              |
| ------------------------------------ | ---------- | --------------------------------------------------------------------------------- |
| Twixer のカフェ（post-103・2枚目）   | 1200 × 900 | テーブル越しに笑う二人。左が黒髪ボブ、右が橙髪。制服か私服で、両方の顔が見える。  |
| Twixer のアルバム（post-104）        | 1200 × 900 | 同じ二人が隣に並ぶ。古いアルバムの写真らしく、彩度を落として端を少し退色させる。  |
| Talkup の入学式（fbp-201）           | 1200 × 900 | 制服の二人が桜の下に並ぶ。卒業式画像と照合できるよう、二人の顔を正面に寄せる。    |
| Talkup のカフェ（fbp-203）           | 1200 × 900 | post-103 のカフェと同じ人物・服・席を、少し異なる角度から撮る。両方の顔が見える。 |
| 旧ブログのコンテスト受賞作（再生成） | 1200 × 800 | 川沿いから橋と夕日を撮った横構図。川面に夕日が映り、橋の輪郭が見える風景写真。    |
